# Smarter Practice public development preview

This repository contains the static, client-safe build of the Smarter Practice website redesign for public review.

- The preview is intentionally excluded from search indexing.
- The inquiry form demonstrates the experience and does not send information.
- Client identities, private source history, credentials, and production configuration are not included.
- The current production website and DNS are not connected to this repository.

The published preview is available at <https://jeremyphelps-sp.github.io/smarterpractice-site-preview/>.
